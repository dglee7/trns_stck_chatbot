# 협의체 자료 서식 규칙

pptx 작업은 `pptx` 스킬을 따르고, 아래 규칙을 항상 적용한다.

1. **단위 위치**: 단위 문구는 항상 해당 표의 **우측 상단 끝자리**(우측 정렬, 박스 오른쪽 끝 = 표 오른쪽 끝). 표마다 단위를 둔다. 예: `(단위: 억원, %, %p)`, `(단위: %)`.
2. **헤더 하단선**: 표 헤더(파란색 DDEBF7 영역)의 하단선은 항상 **0.5pt(6350 EMU) 회색 BFBFBF**. 셀 병합(rowSpan/vMerge/hMerge) 영역에서 검은색 선(000000)이 남기 쉬우므로 헤더 마지막 행의 `lnB`와 그 아래 첫 행의 `lnT`를 모두 지정한다.
3. **용어**: "변화" 대신 **"증감"**(차이값) 또는 **"증감율"**(비율)을 쓴다.
4. **부호**: **음수에만 ▲**를 붙이고(▼ 사용 안 함), 양수는 기호 없이 숫자만 쓴다. 단, **퍼센트포인트(%p)** 값은 양수에 `+`를 허용한다. 0은 `-`. 기존 색(양수 빨강, 음수 파랑)은 유지.

## 적용·점검
`python3 scripts/apply_rules.py in.pptx out.pptx` 로 위 규칙을 일괄 적용한다(1~4 모두; 이미 적용된 파일에 다시 돌리면 ▲ 부호가 뒤집히므로 **원본(규칙 적용 전) 파일에만** 실행). 적용 후 LibreOffice로 렌더링해 확인하고, 헤더 행의 `lnB`/`lnT`에 `000000`이 없는지 XML로 검사한다.
